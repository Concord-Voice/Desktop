## Review boundaries

A imports the applicable Alpha CI inputs. The local import was byte-for-byte;
mandatory full-history privacy cleanup also scopes private deployment nodes out
of the published import. B contains the directory relocation and CI adaptations.
This privacy requirement prevents the published A commit from being entirely
verbatim; the implementation and validation changes are listed below.

A full-history scan evaluates every reachable blob, including deleted files.
Secret scanners use an external trusted configuration with no added suppression.
The privacy review distinguishes actual private infrastructure from public
network definitions, synthetic security fixtures, public operator links and
security-detector constants. Exact reviewed lines/literal-and-path pairs are
recorded externally; an unfamiliar path or value still fails. The public IOC
package identifiers are preserved so the scanner can still recognize them.

The scrub preserves deterministic recovery-vector bytes as numeric octets.
The initial baseline missed several consumers; B applies the corrected decoder
transformation to every consumer. All 147 consumer tests pass. No existing test
was deleted or quarantined to repair this. The baseline is repaired forward in
this PR rather than force-pushing private main.

## P — paths, identities and standalone inputs

- Move `client/desktop` to `desktop` and `dev-tooling/concord-bridge` to
  `tools/concord-bridge`; update build, test, fixture, legal and workflow paths.
- Keep cryptography and the event schema in-tree. The source has no root shared
  directory; its unused shared alias remains a root-relative alias.
- Keep only contract fixtures and definitions required by existing parity tests
  from the server source tree. No server service is built here.
- Rewrite repository identity in workflow guards, pinned calls and verifiers,
  including mixed-case identity tests. Preserve Alpha issue links.
- Keep protected calls pinned to Desktop main. During bootstrap, that commit
  has no workflows: pin, call-graph and reusable-call contract failures are
  expected. Their tests remain enforcing and run in separate steps.
- Keep the scan-selection output schema and malformed-input rejection; select
  only Desktop-owned scanners and coverage. Go is owned by Self-Hosted and Sonar
  remains deferred. Retarget obsolete private-path matcher inputs to explicit
  synthetic policy fixtures, retaining all boundary and routing cases.
- Preserve the signed-workflow mutation suite using synthetic fixtures; its
  checked-in-tree assertion now checks the unsigned Desktop contract. Hosted
  classification workflow snapshots are test data, not executable workflows.
- Scope NOTICE regeneration to Desktop and bridge runtime dependencies. Keep
  generic generator fixture tests, while the production CLI uses `--desktop-only`.
- Use the checked-out CodeQL configuration during bootstrap; Go queries remain
  with Self-Hosted. JavaScript/TypeScript and Actions runner sizes are unchanged.
- Full-history privacy edits remove private prose and metadata, preserve public
  detector constants and IOC identifiers, and remove whole private ignore lines.

## C — credential and publication ownership

- Hosted retains deployment, Cloudflare, IOC refresh and publication credentials.
- Signing, notarization, environment/OIDC credential setup and release attestations
  move to Release-Ops in D2. Desktop builds unsigned artifacts with read-only
  packaging permissions, no release environment and no signing secret references.
- Remove release creation, tag writes, release synchronization and public-mirror
  dispatch from Desktop packaging. The update feed remains unchanged.
- Generate an empty Google desktop OAuth secret for unsigned test builds, so
  those builds do not enable Google sign-in. No OAuth credential is copied.
- Sonar and its protected credential canary are deferred until Alpha issue 2949 closes.

- Add an unsigned-workflow verifier and adversarial tests for credentials,

- Wire the existing pin, scan-verdict, CodeQL graph and call-contract suites into
  Desktop CI. Bootstrap-dependent suites run independently so one failure cannot
